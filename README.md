# Getting and Cleaning Data Course Project

This repository contains the R code and documentation for the Coursera "Getting and Cleaning Data" course project.

## Repository Contents
* `run_analysis.R`: The R script that downloads, cleans, and transforms the raw dataset into a tidy dataset.
* `CodeBook.md`: Describes the variables, data, and transformations applied during the analysis.
* `README.md`: Explains how the script works and how the files are structured.

## How to Run the Script
1. Open RStudio or an R console.
2. Set your working directory.
3. Source and execute `run_analysis.R`.
4. The script will automatically download the required dataset, perform the data cleaning steps, and output a file named `tidy_data.txt`.
